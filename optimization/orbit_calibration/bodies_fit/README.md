# Body Fit Snapshots

This folder contains the preserved body-fit snapshots available in the final project material:

```text
bodies_fit_id_4.mat   Cindrel
bodies_fit_id_5.mat   Aurelios
bodies_fit_id_6.mat   Tharos
bodies_fit_id_7.mat   Glacior
bodies_fit_id_8.mat   Ashkara
bodies_fit_id_9.mat   Varuun
bodies_fit_id_10.mat  Xerion
bodies_fit_id_1000.mat Nyxar
```

Each file stores a `bodies_fit` MATLAB struct representing the full system after fitting the target body. The filename identifies the body that was being fitted.
